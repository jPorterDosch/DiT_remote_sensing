# rs_prompts.json: fixed remote-sensing prompt set for the prompted-generation grid

26 prompts, written down on 2026-11-11 **before any sample was drawn**. The six rows of the paper
figure are the entries with `"figure": true`, also fixed here; the other 20 are sampled and kept so the
full set can go in the supplement. Do not edit this file after the first production run: the sampler
stamps the sha1 of the caption list into every manifest and the figure refuses arms whose lists differ.

| `source` | n | what is verbatim | reference |
|---|---|---|---|
| `clip-eurosat` | 10 | template `'a centered satellite photo of {}.'` and all ten class strings | OpenAI CLIP zero-shot prompts, `data/prompts.md`, EuroSAT section: https://raw.githubusercontent.com/openai/CLIP/main/data/prompts.md |
| `clip-resisc45` | 8 | template `'satellite photo of a {}.'` and the class strings | same file, RESISC45 section (18 templates, 45 classes). The eight classes were chosen by us: object classes that take the article "a" |
| `text2earth` | 4 | the sentence, minus the trailing comma the paper prints inside its quotation marks | Text2Earth, arXiv 2501.00895v2, Section V-D (first three) and Section VI, Fig. 16 failure case ("Twelve storage tanks ...") |
| `diffusionsat-format` | 4 | only the FORMAT `a [fmow] satellite image [of a <object>] [in <country>]` (bracketed parts optional) | DiffusionSat, arXiv 2312.03606v2, Table 5, Appendix A.2.1. The dataset tag is dropped; object and country are ours, picked to match this paper's tasks (PV4GER: Germany, Brick Kiln: Bangladesh, ForestNet: Indonesia) plus one port |

Checked against the fetched pages on 2026-11-11. DiffusionSat prints no complete example prompt as
text (its Fig. 8 examples are inside an image), so nothing in the last group is a quote.

Sampling (`prompt_gen.py --prompts`): FLUX.1-dev text-to-image operating point, the same as the COCO
check (`results/gen/prompt_gen_coco/README.md`): 512 px, 28 steps, guidance 3.5, seed 0, one fixed noise
draw per prompt index shared by every arm. The adaptation itself ran at the null prompt, guidance 1.0,
224 px, so every adapted arm is off its training condition here by construction.
